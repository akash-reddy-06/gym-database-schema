# Relational Gym Tracker Database
A normalized PostgreSQL database schema designed to track bodybuilding, boxing, and fitness workouts. 

## Features
- **Relational Integrity:** Tracks user profiles, exercise dictionaries, daily sessions, and individual sets using `FOREIGN KEY` and `ON DELETE CASCADE`.
- **Data Science Ready:** Structures telemetry data to allow for advanced volume analytics, statistical grouping, and predictive modeling.
